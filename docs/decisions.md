# Decisions

A record of the choices I've made for this build and why. Newest first.

---

## 2026-11: Throwing everything into GitHub so I use it more! 

**Decision:** Document this build on GitHub from the planning stage onward, and put my other projects here too.

**Options considered:**
- Keep notes locally until the build is done
- Track everything on GitHub from day one

**Why:** I want to use Git and GitHub every day so they become second nature. Documenting as I go also creates an honest record of how I plan, research, and solve problems.

**Open questions:**
- Which projects to add next (home lab, CS coursework)

---

## 2026-11: Raspberry Pi 5 as the host

**Decision:** Run Home Assistant OS on a dedicated Raspberry Pi 5.

**Options considered:**
- Raspberry Pi 5
- Running Home Assistant on my main PC
- A dedicated mini PC

**Why:** A dedicated device keeps the smart home running 24/7 without depending on my main computer. The Pi 5 is small, low-power, and well supported by Home Assistant.

**Open questions:**
- Which storage to use (microSD vs. SSD)
- Which power supply and case to buy

---

## 2026-11: Home Assistant only (dropped the MagicMirror idea)

**Decision:** Focus the Pi entirely on Home Assistant instead of also building a MagicMirror smart mirror.

**Options considered:**
- MagicMirror smart mirror plus Home Assistant
- Home Assistant only

**Why:** My real goal is controlling the whole house from one place. A smart mirror added hardware and complexity without serving that goal, so I cut it to keep the project focused.
